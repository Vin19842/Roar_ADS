# ROAR Ads Frontend

A modern, cinematic web experience for ROAR Advertising - a creative production house specializing in cinematic ad films, documentaries, corporate videos, social media promos, TV commercials, and animation.

## 🎬 Project Overview

This is the frontend application for ROAR Ads, built as a performant, accessible, and visually stunning web platform showcasing video production and advertising services. The application uses modern React with TypeScript for type safety and developer experience.
